# GeoNews

GeoNews es una aplicación del tiempo que permite a los usuarios consultar la previsión meteorológica de sus localizaciones de interés, así como la calidad del aire y las noticias recientes de esas ubicaciones. La aplicación está diseñada para ofrecer una visualización clara y atractiva de los datos mediante gráficos optimizados.

## Características

- **Agregar localizaciones** por nombre o por coordenadas GPS.
- **Visualización del tiempo actual** y **predicción meteorológica** para los próximos 7 días.
- **Consulta de la calidad del aire** en cada localización guardada.
- **Acceso a noticias recientes** de la localización seleccionada.
- **Interfaz optimizada** con gráficos intuitivos para una consulta rápida de los datos.
- **Gestión de favoritos**: guardar localizaciones preferidas para acceder a ellas rápidamente.
- **Importación y exportación de localizaciones**: permite trasladar las localizaciones guardadas entre dispositivos.

## Instalación y Uso

1. Clonar el repositorio:
   ```sh
   git clone https://github.com/tuusuario/geonews.git
   ```
2. Abrir el proyecto en Android Studio.
3. Construir y ejecutar la aplicación en un emulador o dispositivo físico.
4. Agregar localizaciones y comenzar a visualizar el clima y noticias de cada una.
